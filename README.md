# AI-Powered MCQ Assessment System
## Overview
This project is an intelligent multiple-choice question (MCQ) assessment platform designed to enhance learning through AI-powered real-time answer evaluation and feedback. Using GeminiAI, the system provides detailed explanations, additional facts for correct answers, analyzes misconceptions for incorrect answers, and generates personalized study notes to help users improve their understanding.

## Features
Interactive MCQ quizzes with instant AI evaluation.

Detailed explanations for each question.

Additional educational facts for correct answers.

Insightful mistake analysis and improvement suggestions for wrong answers.

End-of-quiz summary highlighting strengths and areas for improvement.

AI-generated short notes tailored to weak topics for quick revision.

Support for human-in-the-loop (HITL) review to ensure feedback quality.

Responsive web interface designed for ease of use across devices.

## Design Documents
Figma Prototypes: Designed collaboratively by Kowsika and Mugunthan, illustrating UI and UX flows.

Low-Level Design (LLD): Created collaboratively, detailing architecture, modules, data flow, and API design.

## Usage
Register or log in to start an assessment.

Answer MCQs and receive instant AI feedback with explanations.

Review your detailed performance summary after each quiz.

Access AI-generated short notes on topics needing improvement.
